## 2. 需求摘要

薪资项「输入类型」在原有的 金额、开关 之外新增 **文本** 与 **单选下拉** 两种；单选下拉需要维护「选项配置」（英文逗号分隔）。
新增的两种类型要一路贯通到：算薪规则配置 → 员工薪酬档案录入 → 编辑记录/版本历史的前后值 → 薪资包核对薪资项的「参数值」→ 导出数据源与下载导入模板（国家模板）取数。

| 开关类型的调整金额「-」、金额类型回归 | 环境内缺少可控的开关类型薪资项 + 调整单组合；金额类型回归已由存量用例 `薪资包结算` 覆盖 |
| 多语言（zh/en 文案）、icon 样式/位置、移动端 | 不可自动化/无业务价值 |
| 跨客户、跨租户 ID、非法枚举传参 | 前端造不出来，公司口径不做 |

### 写库情况说明（对应 AGENTS.md 第 5 节）

- 本轮**不需要任何 DB 写操作**（无 `db_update` / `delete` / `insert` / DDL）。
- 造数全部走业务接口（创建薪资包 → 校验 → 作废），清理也走接口（`PUT /center/payrollSalaryPackage/packageVoided`）。
- 只读查询仅限测试环境（`ENV=测试环境`），SQL 都带 `where`。
- 若后续阶段发现必须 `db_update`（例如需要把某条薪资项改成文本类型），会**先按标准话术向你确认目标表/影响行数/恢复方案**，确认后才写进用例。
