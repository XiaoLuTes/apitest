# 用例编写模板与口径

> 对应文件：
> - 接口用例模板：`api/testcase/test_TEMPLATE_api.xlsx`（本身能过 lint，可整表复制）
> - UI 用例模板：`ui/testcases/_TEMPLATE_ui_case.yaml`（文件内注释含全部动作说明）
> - 定位器模板：`ui/config/locators/_TEMPLATE_locators.yaml`
> - 执行手册：`../AGENTS.md`；框架说明：`../README.md`

---

## 1. 复制流程

**接口用例**

```powershell
# 复制模板 → 改名（必须 test_ 开头才会被 lint 与项目注册识别）
Copy-Item api\testcase\test_TEMPLATE_api.xlsx api\testcase\test_<主题>.xlsx
# 改完注册到 api/config/setting.py 的 TEST_FLIELOADS
#   "项目名": "testcase/test_<主题>.xlsx",
python run.py lint --project <项目名>
python run.py api <项目名>
```

**UI 用例**

```powershell
Copy-Item ui\testcases\_TEMPLATE_ui_case.yaml ui\testcases\<项目>\<用例>.yaml
# 定位器：没有现成的就采集后写入 ui/config/locators/<项目>.yaml（可参考 _TEMPLATE_locators.yaml）
python tools/ui_capture.py --menu "<一级/二级/三级菜单>" --headless
# 注册到 ui/config/settings.py 的 PROJECT_CONFIGS（PAGE_NAME / TESTCASES_PATH /
#   ELEMENT_LOCATORS / LOADING_SELECTOR: "#loader-wrapper"）
python run.py lint --suite ui --project <项目名>
python run.py ui <项目名> --headless
```

## 2. 接口用例：列定义

| 列 | 必填 | 说明 |
| --- | --- | --- |
| `case_id` | ✅ | 唯一编号；数据清理用例建议沿用准备/执行的前缀便于追溯 |
| `name` | ✅ | **以「管理端｜」或「员工端｜」开头**（决定请求 host 与鉴权头） |
| `headers` | ✅ | 一般写 `${headers_admin}` 或完整 JSON `{"Authorization": "Bearer ${access_token_admin}"}` |
| `method` | ✅ | `GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS` + 专用动作（见下） |
| `url` | ✅ | 相对路径（如 `/api/center/xxx/list`），host 由 `name` 的端决定 |
| `data` | ✅ | GET/POST 参数（JSON）；`db_select`/`db_update` 写 **SQL**；`download` 写 `{"dir","var"}` |
| `response` | — | 接口返回原文会回写到这里（失败排查用，建议保留该列） |
| `extract` | — | `{"变量名": "$.data.id"}`，产出变量给后续用例用 `${变量名}` |
| `validata` | ✅ | 断言：普通接口写 JSON `{"$.code":200,"$.rows[0].id":"${demo_id}"}`；<br>`db_select` 写 `字段=值`（如 `status=2`）；`db_update` 写影响行数 |
| `result` | — | 框架回写通过/失败 |
| `retry` | — | 只认**纯数字**或 dict；异步状态流转用（如 `5`）；写 `{"times":5}` 字符串会报错 |
| `备注` | 建议 | 写清"这条用例为什么存在/数据从哪来" |

**三 sheet 分工（固定）**：`数据准备` → `测试执行` → `数据清理`，按此顺序执行。
准备阶段造数并 `extract` 出 ID；执行阶段用 `${id}`；清理阶段删干净，**跑完不留脏数据**。

**专用动作（method 列）**

| method | 用途 | data / validata |
| --- | --- | --- |
| `db_select` | 查库校验 | data = SQL；validata = `字段=值`（多字段逗号分隔） |
| `db_update` | 改库准备/清理 | data = SQL（含 `SET ...`）；validata = 影响行数；**SQL 不要写进 validata** |
| `download` | 下载文件 | data = `{"dir": "reports/downloads", "var": "文件变量名"}`；不支持断言 |
| `editexcel` | 改 Excel 后上传 | data = `{"file": "...", "cells": {...}}` 或 `index_cells`（按国家模板指标编号填） |
| `upload` | 上传文件 | data = `{"url": "...", "file": "${变量}"}` |
| `payrollconfirm` | 薪资包结算确认上传 | 由 `payroll_util.build_confirm_body` 拼 excelDistrictDataMap |
| `pkgquery` | 薪资包按ID查询 | data = `{"code": "SAL-..."}`；validata = `pkg_status=0,pkg_country=Canada` |

## 3. UI 用例：结构

```yaml
test_cases:
- id: 项目-01-场景            # 唯一
  name: 项目-场景-具体校验点    # 报告与提单里的用例名
  page: payroll_package_page   # 必须是本项目 PAGE_NAME 里的页面对象
  steps:
    - step_name: 1、做什么       # 步骤名会进报告/证据/提单
      element: pkg_code_input   # 元素名，必须在定位器文件里存在
      action: input             # 动作，取值见模板文件底部清单
      data: 'SAL-20261112-0001' # 输入值/期望值/变量名（按动作语义）
```

动作清单、`data/expected` 语义、变量规则都写在 `ui/testcases/_TEMPLATE_ui_case.yaml` 的注释里，**写用例前先看那份**。
要点：`{变量}` 由 `VariableStore` 替换；要输出字面量大括号写 `{{变量}}`；`${变量}` 是接口侧写法，在 UI 用例里无效。

## 4. 用例设计口径（写之前先对齐这几条）

1. **只测前端造得出来的场景**：非法枚举、空必填、跨租户 ID 这类"接口脏数据健壮性"不做（公司口径：前端有拦截即可）。
2. **造数路径必须页面可达**：需要"包含全部标签"就用跨组标签组合，别用页面点不出来的配置。
3. **断言要验关键业务字段**：`code=200` 只能证明没报错；金额、状态、数量、落库结果才是断言重点。
4. **三 sheet + 清理**：造了数据必须清理；跑完自检无残留（如薪资包 `status=5`、绑定关系 `del_flag=2`）。
5. **数据唯一化**：日期/名称带唯一后缀（时间戳/编号），否则重跑会撞历史数据（如销假后同一时段不可重提）。
6. **`retry` 只用于异步状态流转**，不要用它掩盖真正的失败。
7. **明确列出「不做」的用例**并在需求文档里写原因（例：未配置国家模板的场景不做）。

## 5. 命名规范

| 侧 | 规范 | 例 |
| --- | --- | --- |
| 接口 `name` | `端｜模块｜场景-预期` | `管理端｜薪资包管理｜按薪资包ID查询-命中` |
| 接口 `case_id` | 三位数字递增；准备用 P/1xx、执行用 1xx、清理用 C/2xx | `001` / `T011` / `T021` |
| UI `id` | `项目-序号-场景` | `薪资包管理-02-查询不存在的薪资包ID` |
| UI `name` | `项目-场景-校验点` | `薪资包管理-查询不存在的薪资包ID-列表为空` |
| 步骤 `step_name` | `序号、动作对象 + 动作` | `3、点击「搜 索」` |

## 6. 自检（提交前必跑）

```powershell
python run.py lint --project <接口项目名>
python run.py lint --suite ui --project <UI项目名>
```
- 有 **ERROR** 不许执行，先改用例
- 模板本身是 lint 干净的（接口模板 10 条 E0 W0），可作为格式基准
