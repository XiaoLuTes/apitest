## 4. 维护约定

1. 公共数据新增/变更：直接改本文件，写清「值 / 说明 / 状态」。
2. 数据失效（被作废、被删除、月份过期）：状态改 `❌失效` 并注日期，**不要删行**（便于回溯旧用例为什么失败）。
3. `📌会变` 的数据一律**按业务单号查**，不要写死自增 ID。
4. 造数必须配清理（各用例集的「数据清理」sheet），跑完环境应无残留。
5. 项目专属数据不要写在这里，写到 `<项目>/测试数据/README.md`。
